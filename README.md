 
# 中文

## TimeFreeze

无人时冻结 Minecraft 服务器的时间与天气，有玩家进入后自动恢复。

### 功能
- 最后一个玩家离开 → 昼夜循环与天气立即冻结
- 第一个玩家进入 → 昼夜循环与天气立即恢复
- 卸载插件后自动恢复默认状态

### 兼容性
- **PaperTimeFreeze**：Paper / Purpur / Spigot 及所有 Bukkit 系服务端
- **FoliaTimeFreeze**：Folia
- 支持版本：1.20.x、1.21.x、26.1.x、26.2.x

### 安装
将 jar 文件放入服务器的 `plugins/` 目录，重启服务器即可，无需额外配置。

# English

## TimeFreeze

Automatically pauses the daylight cycle and weather when no players are online, and resumes them when players join.

### Features
- Last player leaves → day/night cycle and weather freeze immediately
- First player joins → day/night cycle and weather resume immediately
- Automatically restores the default state when the plugin is unloaded

### Compatibility
- **PaperTimeFreeze**: Paper / Purpur / Spigot and all Bukkit-based servers
- **FoliaTimeFreeze**: Folia
- Supported versions: 1.20.x, 1.21.x, 26.1.x, 26.2.x

### Installation
Drop the jar file into your server's `plugins/` folder and restart. No extra configuration needed.
