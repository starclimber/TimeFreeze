# TimeFreeze

无人时冻结 Minecraft 服务器的时间与天气，有玩家进入后自动恢复。

Automatically pauses the daylight cycle and weather when no players are online, and resumes them when players join.

## 功能 / Features

- 最后一个玩家离开 → 昼夜循环与天气立即冻结 / Last player leaves → day/night cycle and weather freeze immediately
- 第一个玩家进入 → 昼夜循环与天气立即恢复 / First player joins → day/night cycle and weather resume immediately
- 卸载插件后自动恢复默认状态 / Automatically restores the default state on unload

## 兼容性 / Compatibility

| 版本 / Version | 服务端 / Server |
|---------------|----------------|
| PaperTimeFreeze | Paper / Purpur / Spigot 及所有 Bukkit 系服务端 |
| FoliaTimeFreeze | Folia |

支持版本 / Supported versions: `1.20.x`, `1.21.x`, `26.1.x`, `26.2.x`

## 安装 / Installation

将 jar 文件放入服务器的 `plugins/` 目录，重启服务器即可，无需额外配置。

Drop the jar file into your server's `plugins/` folder and restart. No extra configuration needed.
