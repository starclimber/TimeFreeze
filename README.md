# 中文：

TimeFreeze

无人时冻结 Minecraft 服务器的时间与天气，有玩家进入后自动恢复。
功能

- 最后一个玩家离开 → 昼夜循环与天气立即冻结
- 第一个玩家进入 → 昼夜循环与天气立即恢复
- 卸载插件后自动恢复默认状态

兼容性

- PaperTimeFreeze：Paper / Purpur / Spigot /Bukkit 1.20.x，1.21.x，26.1.x，26.2.x
- FoliaTimeFreeze：Folia 1.20.x，1.21.x，26.1.x，26.2.x

安装

将 jar 文件放入服务器的 
"plugins/" 目录，重启服务器即可，无需额外配置。

# English：

TimeFreeze

Automatically pauses daylight cycle and weather when no players are online, and resumes when players join.
Features

- Last player leaves → Day/night cycle and weather freeze immediately
- First player joins → Day/night cycle and weather resume immediately
- Automatically restores default state on plugin unload

Compatibility

- PaperTimeFreeze：Paper / Purpur / Spigot /Bukkit 1.20.x，1.21.x，26.1.x，26.2.x
- FoliaTimeFreeze：Folia 1.20.x，1.21.x，26.1.x，26.2.x

Installation

Drop the jar file into your server's 
"plugins/" folder and restart. No extra configuration needed.
